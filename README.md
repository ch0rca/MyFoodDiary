 >광고나 리뷰이벤트로 부풀려진 기존 네이버와 카카오맵, 맛집에 지쳤다면?🤦

 >> 1. 내가 가야할 맛집을 먹부림 캘린더로 먹고 싶은 음식과 식당을 편하게 관리
 >> 2. 개인의 유저가 추가한 식당과 메뉴를 기준으로 맛집과 메뉴 추천  

## How to start
### 1. Install python tkinter
```bash
pip install tk
```
### 2. Install reqeusts for HTTP Requestㅜ

```bash
pip install requests
```
### 3. Install JSON module to parse the HTTP requset body
```bash
pip install json
```
